# CODEXA — استوديو البرمجة

استوديو برمجة عربي RTL، فاخر ومصمم للهاتف أولاً. يوفر إدارة مشاريع وملفات حقيقية، محرر CodeMirror، معاينة HTML/CSS/JavaScript مع الموارد المحلية، وميزة بناء APK. لا يحتاج تشغيل الموقع إلى حساب أو مفتاح API خارجي.

## البدء

من معاينة مشروع CODEXA افتح لوحة **Preview**. لإنشاء APK اختر زر **APK** في الواجهة، اختر الاسم والحزمة والأيقونة وملف HTML للبداية، ثم وافق صراحةً على إرسال ملفات المشروع إلى خدمة البناء. تعمل الخدمة على إنشاء APK حقيقي والتحقق من توقيعه قبل تنزيله؛ لا تستخدم ZIP أو HTML بديلاً باسم APK.

للتطوير محلياً:

```sh
pnpm install
pnpm dev
```

يقدم خادم Node الواجهة وAPI البناء على المنفذ `3000`، أو على `PORT` إذا حُدد. يعلن `/manus-routes.json` عن المسار `/`، وتجيب `/api/health` عن صحة الخادم. أوامر التحقق:

```sh
pnpm build
pnpm check:server
```

## اللغات والمعاينة

يوفر المحرر أكثر من 50 خياراً لغوياً وقوالب بداية، ويكتشف اللغة من الامتداد مع اختيار يدوي لكل ملف. PHP وProtocol Buffers وDart وNginx وHTTP ظاهرة صراحةً كخيارات **تحرير نصي** لعدم توفر محلل CodeMirror متخصص لها؛ تبقى ملفاتها قابلة للتحرير. المتصفح يشغّل HTML وCSS وJavaScript. لا تحول الواجهة Python أو Java أو C/C++ أو Rust أو React/TSX إلى runtimes أو compiler أو تطبيقات أصلية.

تجمع المعاينة ما يمكن تحليله من مراجع HTML/CSS/JavaScript المحلية النسبية، CSS `@import`، وخرائط `importmap`. كما تعرض iframes المحلية التي تشير إلى ملفات HTML محلية مع الموارد التي يمكن تضمينها، وتضيف CSP وsandbox لكل إطار دون `allow-same-origin`. تُعرض SVG وMarkdown وJSON والصور بطريقة مناسبة. يحجب CSP الاتصالات الخارجية وHTTPS/WSS افتراضياً؛ يمكن السماح بها صراحةً من شريط المعاينة، وتظهر المراجع المحلية المفقودة ضمن التشخيصات. تُعزل صفحات `srcdoc` أيضاً. راجع شيفرة المشاريع غير الموثوقة قبل تشغيلها.

## المشاريع والنسخ الاحتياطي

تُحفظ المشاريع داخل IndexedDB بالمتصفح والجهاز الحالي؛ لا تُرفع ولا تتزامن تلقائياً بين الأجهزة، وقد تفقدها إذا مسحت بيانات المتصفح. صدّر ZIP احتياطياً لحفظ الملفات واسم المشروع وملف البداية واختيارات اللغات وهوية Android والمجلدات الفارغة. استعادة ZIP الخاص بـCODEXA تنشئ مشروعاً مستقلاً دون استبدال المشاريع الحالية، وZIP عام يندمج في المشروع المفتوح فقط إذا لم تتعارض مساراته. تُرفض مسارات الأسرار وملفات المفاتيح وتصادمات أسماء الملفات والمجلدات.

لأمان ذاكرة المتصفح: الحجم المضغوط للـZIP حتى 24 MiB، وبحد 2500 مدخل، و500 ملف، و4 MiB لكل ملف، و20 MiB مجموعاً بعد الفك؛ وتُفحص أحجام ZIP المعلنة قبل فك الملفات. ملف بيانات النسخة الاحتياطية محدود بـ1 MiB.

## بناء APK

قبل البناء، يحدد المستخدم اسم التطبيق ومعرّف الحزمة والأيقونة وصفحة HTML البداية. هناك موافقتان منفصلتان: موافقة إرسال الملفات مؤقتاً إلى خادم البناء، وإذن الشبكة الاختياري للتطبيق الناتج. دون إذن الشبكة لا يضمّن APK صلاحية Android INTERNET ويحجب الطلبات والروابط الخارجية. عند تفعيل الإذن يسمح بطلبات HTTPS/WSS فقط؛ يُحظر HTTP غير المشفر دائماً. لا تُفتح روابط `mailto:` و`tel:` من APK. تنقل روابط HTTPS الخارجية المنقورة إلى المتصفح فقط عند تفعيل الإذن.

يدعم WebView عنصر `input type="file"` عبر منتقي ملفات Android، ويرسل اختيار النظام إلى صفحة الويب دون طلب إذن تخزين عام؛ الوصول يقتصر على العنصر الذي يختاره المستخدم. طلبات الكاميرا والميكروفون والموقع من صفحة التطبيق المحلية تمر عبر حوار Android وقت الحاجة، ولا تُمنح إلا بعد موافقة المستخدم؛ الأذونات غير المدعومة أو الطلبات من أصل آخر تُرفض. لا يمنح التطبيق الأذونات تلقائياً.

زر الرجوع يعود في سجل WebView قبل إنهاء الشاشة. روابط التنزيل الخارجية HTTPS تستخدم DownloadManager ومجلد Downloads فقط عند تفعيل إذن الشبكة؛ data URL وblob URL وصفحات `<a download>` تُجهّز محلياً ثم تعرض نافذة Android ليختار المستخدم مكان الحفظ، مع حد 24 MiB لها. HTTP الخارجي محجوب. يتكيف النشاط مع لوحة المفاتيح (`adjustResize`) ويستخدم تسريع العتاد، مع تفعيل DOM Storage وWeb SQL/Database في WebView.

يقبل خادم البناء حتى 500 ملف، و20 MiB إجمالاً، و4 MiB للملف الواحد، وبناء واحد متزامن وستة أبنية في الدقيقة. يتحقق من نوع الناتج وتوقيعه ويحذف ملفات العمل المؤقتة. يفتح WebView صفحة HTML المختارة محلياً مع موارد الويب المرفقة؛ لا يشغّل برامج Python/Java/C/C++/Rust الأصلية ولا يُضمّن مفاتيح خدمات خارجية نيابةً عن المستخدم.

يستخدم الاختبار المحلي مفتاح Android **debug ثابتاً مشتركاً** للتجربة الجانبية فقط؛ لا يصلح لـGoogle Play أو لحماية إصدار إنتاجي. أُنشئ APK حقيقي محلياً وتحقق من package metadata والتوقيع وإذن الإنترنت في نسختين؛ لم يُختبر تثبيته على جهاز Android فعلي. إعداد توقيع Release خاص وآمن غير مهيأ.

## التشغيل في الإنتاج

في صورة الإنتاج، يجهز Dockerfile JDK/Android SDK الرسميين في مرحلة مستقلة، ثم يشغّل Node لخدمة الواجهة و`POST /api/build/apk` ومسار صحة `/api/health`. لا توجد قاعدة بيانات للمشاريع المحلية. يتطلب بناء صورة الإنتاج تنزيل أدوات Android من مستودعات Google. لم يُبنَ Dockerfile أو يُنشر الموقع علناً من هذه البيئة لعدم توفر Docker CLI وعدم طلب نشر عام.
